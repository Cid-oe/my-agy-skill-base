# Ponytail

Category: execution | Priority: high | Cost: high | Latency: slow

**Use when:** Use for careful, higher-stakes execution passes where correctness and traceability matter more than speed — e.g. changes to shared or critical code. The deliberate, thorough counterpart to caveman.
