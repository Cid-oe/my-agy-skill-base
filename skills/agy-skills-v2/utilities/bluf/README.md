# BLUF (Bottom Line Up Front)

Category: utilities | Priority: low | Cost: low | Latency: fast

**Purpose:** Put the conclusion or direct answer first, then supporting detail — never bury the lede in setup, caveats, or process narration.

**Use when:** Use when a response could bury the key answer under preamble or reasoning — lead with the bottom line first, supporting detail after.

**Consumes:** DraftResponse  
**Produces:** ReorderedResponse
