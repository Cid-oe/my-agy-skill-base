# Skill Creator

Category: utilities | Priority: low | Cost: medium | Latency: medium

**Purpose:** Create new skills with real, specific content — a clear goal, a concrete trigger description, and workflow steps written for that skill's actual job, not a copied template.

**Use when:** Use when a new recurring task or workflow would benefit from its own skill — to draft a properly structured, fully filled-in SKILL.md rather than a placeholder template.

**Consumes:** RecurringTaskPattern  
**Produces:** NewSkillDefinition
