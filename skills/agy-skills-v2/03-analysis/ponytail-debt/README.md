# Ponytail Debt Ledger

Category: quality | Priority: medium | Cost: low | Latency: fast

**Purpose:** Maintain a persistent ledger of technical debt items across time: added, resolved, and still open — not just a one-off snapshot.

**Use when:** Use to maintain a running ledger of known technical debt over time — what's outstanding, what's been paid down — so debt is tracked rather than forgotten.

**Consumes:** DebtInventory, PaydownRecord  
**Produces:** DebtLedger
