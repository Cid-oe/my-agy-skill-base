# Documentation Sync

Category: quality | Priority: medium | Cost: low | Latency: medium

**Purpose:** Keep documentation accurate as code changes, updating only what's now wrong rather than rewriting wholesale.

**Use when:** Use after code changes that affect behavior, APIs, or setup steps, to check whether existing documentation (README, docstrings, API docs) still matches reality.

**Consumes:** ExecutionResult  
**Produces:** UpdatedDocs
