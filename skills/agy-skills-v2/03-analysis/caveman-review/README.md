# Caveman Review

Category: quality | Priority: medium | Cost: low | Latency: fast

**Purpose:** Give fast, direct feedback on a small change: does it do what it claims, is anything obviously wrong — without a full review process.

**Use when:** Use for a fast, blunt review of a small, low-risk change — correctness check without full ceremony. The terse counterpart to ponytail-review.

**Consumes:** ExecutionResult  
**Produces:** ReviewVerdict
