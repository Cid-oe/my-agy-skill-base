# Ponytail Review

Category: quality | Priority: high | Cost: high | Latency: slow

**Purpose:** Give a thorough review of a significant change: correctness, edge cases, and consistency with existing patterns — not just 'does it run.'

**Use when:** Use for a thorough review pass on a significant or high-risk change — correctness, edge cases, and consistency with existing patterns. The deliberate counterpart to caveman-review.

**Consumes:** ExecutionResult, RepositoryMap  
**Produces:** ReviewVerdict
