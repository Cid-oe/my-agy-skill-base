# Ponytail Audit

Category: quality | Priority: medium | Cost: medium | Latency: slow

**Purpose:** Produce a concrete inventory of current technical debt: what it is, where it lives, and roughly how costly it is to leave unresolved.

**Use when:** Use to take a point-in-time snapshot of a codebase's technical debt — known issues, workarounds, deferred TODOs — as the baseline the ponytail-debt ledger tracks against.

**Consumes:** RepositoryMap  
**Produces:** DebtInventory
