# Prompt Coach

Category: planning | Priority: high | Cost: low | Latency: fast

**Purpose:** Turn a vague or underspecified request into an actionable one, asking only for what actually changes the approach.

**Use when:** Use when a request is ambiguous, underspecified, or likely to produce a poor result as written, to sharpen it into something actionable before executing — with minimal back-and-forth.

**Consumes:** RawRequest  
**Produces:** ActionableRequest
