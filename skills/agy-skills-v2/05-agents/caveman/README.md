# Caveman

Category: execution | Priority: medium | Cost: low | Latency: fast

**Purpose:** Execute simple, well-understood tasks with minimal ceremony: no over-planning, no unnecessary exploration, no padded output.

**Use when:** Use for straightforward, well-scoped execution tasks where speed and minimal overhead matter more than exploratory reasoning — short plan, direct action, quick verify. The terse counterpart to ponytail.

**Produces:** ExecutionResult
