# Gemini Delegate

Category: execution | Priority: low | Cost: medium | Latency: medium

**Purpose:** Delegate a specific, well-justified subtask to Gemini and validate the result before integrating it back into the task.

**Use when:** Use when a specific subtask is genuinely better suited to Gemini — very large context ingestion, multimodal input, or an explicit user request to use it — rather than routing every subtask there by default.

**Consumes:** Subtask  
**Produces:** ValidatedExternalResult
