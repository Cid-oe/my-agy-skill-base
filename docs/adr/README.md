# Architecture Decision Records

ADRs capture **implementation-time** decisions that don't change RFC
contracts (library choices, storage engines, sandbox mechanisms, perf
tuning trade-offs). Contract changes go through `docs/amendments/` instead.

Naming: `AD-00NN-short-title.md`. Template: Context / Decision /
Consequences / Alternatives considered. Numbering is sequential, never
reused (same rule as RFCs, RFC-0000 §5.2).
