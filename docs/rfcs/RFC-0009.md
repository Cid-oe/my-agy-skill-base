# RFC-0009: Number Retirement Record

**Status:** Retired (this number is permanently out of use)
**Series:** AGY AI Operating System
**Date:** 2026-08-21
**Supersedes:** nothing · **Superseded by:** nothing

---

## 1. Purpose

RFC-0009 was reserved during the RFC-0006 dependency declarations for an
**Observation Engine** ("Depended on by: … Observation Engine (RFC-0009)…").
The observability subsystem was subsequently published as **RFC-0015:
Observability**. The number 0009 was therefore never issued to a document and
must not be silently reused — two later RFCs made *conflicting* assumptions
about what RFC-0009 would contain, which is precisely the failure mode a
retirement record exists to prevent.

## 2. History of the slot

| Source | Assumption about "RFC-0009" | Disposition |
|---|---|---|
| RFC-0006 (§ header, §1.4, §9.1) | Observation Engine | **Void** — observability is RFC-0015 |
| RFC-0010 (§ "Dependency on RFC-0008 and RFC-0009") | Token Budgeting subsystem | **Void** — token budgeting is owned interim by the `token-budget` skill and canonically by the future Resource Manager RFC-0016 (see `docs/amendments/RFC-0010-A1.md`) |
| RFC-0012 (§21, "RFC-0018" note) | Token Budgeting ledger | **Void** — same as above |
| RFC-0014 (§6.3.6) | Model routing subsystem (with RFC-0008) | **Void** — model routing is owned interim by the `model-router` skill and canonically by future RFC-0018 (see `docs/amendments/RFC-0014-A1.md`) |

## 3. Rule

Per the RFC process in [RFC-0000](RFC-0000.md): numbers are allocation-only
and are never reused. An unissued number that any document has referenced is
retired by a record like this one rather than reassigned.

## 4. Canonical references

- Observability → **RFC-0015**
- Token / context budget ledger → **future RFC-0016** (Resource Manager &
  Execution Ledger)
- Model registry & routing → **future RFC-0018**

*End of RFC-0009.*
