# RFC-0006a: Event Bus Delivery Guarantee Specification

**Status:** Accepted (Amendment to RFC-0006)  
**Subsystem:** Event Bus  
**Author:** Lead Systems Engineer  

---

## 1. Problem Statement
RFC-0006 specified that Event Bus connects AGY subsystems. To guarantee that Scheduler and Executor operate reliably without lost dispatch events or race conditions, the exact delivery contract and ordering semantics must be formalized.

## 2. Guarantee Specification

1. **Delivery Guarantee:**
   - **At-Least-Once Delivery**: Every published event is guaranteed to be delivered to active subscribers.
   - **Idempotent Consumers**: Every subscriber must handle events idempotently using the unique `Event.id` (UUID).

2. **Ordering Guarantee:**
   - **Per-Key FIFO Ordering**: Events carrying the same `key` (e.g. `planId`, `taskId`, or `skillId`) are strictly delivered in publish order.
   - Independent keys are processed concurrently across worker dispatchers.

3. **Backpressure & Dead-Letter Policy:**
   - Topic queues are bounded (default capacity: 10,000 events).
   - Slow consumers are given bounded buffer time; unhandled/errored events after max retries (default: 3) route to the durable Dead-Letter Queue (`system.dead-letter`).
