# AGY glossary

- **Artifact:** A durable, addressable output produced or consumed by a run.
- **Event Bus:** The shared channel for lifecycle and runtime events.
- **Kernel:** The trusted core services that enforce AGY runtime contracts.
- **Policy Engine:** The component that evaluates permissions and constraints.
- **Skill:** A packaged capability with metadata, dependencies, and an entry point.
- **Skill Registry:** The validated index of discoverable skill packages.
- **Skill Resolver:** The component that chooses suitable skills for a goal.
- **Runtime State:** The scoped state maintained for active work.
