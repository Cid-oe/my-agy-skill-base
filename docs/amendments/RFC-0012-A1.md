# Amendment RFC-0012-A1 — Tool Runtime: renumbering & topic alignment

**Target:** RFC-0012 (Tool Runtime) · **Status:** Proposed · **Severity:** Minor

## Problem

1. §21 declares "RFC-0013 (Required): Credential Store" — RFC-0013 is the
   published Reflection Engine. Its other suggestions (RFC-0014 Circuit
   Breaker, RFC-0015 Marketplace, RFC-0016 Connector SDK, RFC-0017 Contract
   Monitoring, RFC-0018 Tool Token Budgeting) likewise collide with occupied
   numbers.
2. §19.3/§19.4 request `artifact.deleted` events and a topic-namespace
   registry — granted by RFC-0004-A1 R2 and RFC-0006-A1 R1 respectively.
3. §20.6 self-identifies the missing circuit breaker as
   production-critical.

## Reason

Numbering hygiene plus acknowledging that two requested dependencies now
exist. No Tool Runtime behavior changes.

## Impact

Reference corrections only (plus one recorded gap).

## Resolution

**R1 — Renumbering.** Credential Store → **RFC-0017 (Identity, Tenancy &
Credential Store, reserved)**. Circuit Breaker & Reliability → unassigned
pool (recorded as a required pre-production gap, priority per Phase-1 plan).
Capability Marketplace, Connector SDK, Continuous Contract Monitoring, and
tool token-budget integration → unassigned pool / RFC-0016 ledger
integration respectively (see RFC-0000 §8 registry).

**R2 — Dependencies granted.** `artifact.deleted`/`artifact.archived`
events: available per RFC-0004-A1 R2 (alias `artifact.artifact.deleted`).
`tool.*` namespace: registered under RFC-0006-A1 R1 with Tool Runtime as
owner. `tool_dependencies` manifest block: granted by RFC-0002-A1 R1.
Prefix-based capability policy matching: granted by RFC-0003-A1 R5.

**R3 — Recorded gap.** The circuit-breaker omission (§20.6) is a **Phase-1
implementation requirement** for the Tool Runtime, to be specified as a
minor addendum when implementation begins; flagged here so it is not lost.

## Compatibility / Migration

None beyond reference updates.
