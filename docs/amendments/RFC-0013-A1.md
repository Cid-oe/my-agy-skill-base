# Amendment RFC-0013-A1 — Reflection Engine: trigger canonicalization & schema ownership

**Target:** RFC-0013 (Reflection Engine) · **Status:** Proposed · **Severity:** Minor

## Problem

1. §6.1/§4 subscribe to `scheduler.execution.completed|failed|cancelled` and
   `scheduler.task.failed` — events the published RFC-0007 never defined.
2. §19.1/§19.5 place schema/attribute dependencies on RFC-0011 and RFC-0003
   that needed acknowledgment from those sides.
3. §21 suggestions collide with occupied numbers (RFC-0014 Learning Engine
   is "Required" — correct by luck; RFC-0015 Semantic Goal Evaluation is
   actually Observability; RFC-0016/0017/0018 collide with the reserved
   block).

## Reason

Cross-reference hygiene after the Scheduler adopted event publication
(RFC-0007-A1 R5) and after RFC-0003-A1/RFC-0010-A1 granted the requested
attributes/schema ownership.

## Impact

Topic names become real; ownership statements confirmed; renumbering.

## Resolution

**R1 — Triggers.** `scheduler.execution.*` and `scheduler.task.failed` are
canonically defined by RFC-0007-A1 R5 and publishable under RFC-0006-A1's
registry; §6.1's trigger delay (2 s) remains, and §19.5's fallback
(include record refs in the event payload) is the recommended belt-and-
suspenders since the Scheduler now guarantees persistence-before-publish.

**R2 — Ownership confirmations.** Lesson schema: **RFC-0013 §8.4 is the
canonical schema for Reflection Memory lesson-type entries** (accepted by
RFC-0010-A1 R2). `reflection.*` policy attributes and
`reflection.sensitivity_inherited_from`: granted by RFC-0003-A1 R1.
Calibration-observation hand-off to RFC-0011: unchanged; RFC-0011-A1 R5
records the reciprocal.

**R3 — Renumbering.** Semantic Goal Evaluation, Execution Monitor,
Calibration Governance, Reflection Federation → unassigned pool (RFC-0000
§8). Learning Engine dependency correctly points at RFC-0014.

## Compatibility / Migration

None beyond reference updates.
